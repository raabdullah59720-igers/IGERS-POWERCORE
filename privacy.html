IGERS Privacy

This static site does not require an account. Live weather, air-quality, earthquake, orbital-element and ADS-B panels request public data directly from their providers when enabled.

Comments/customer-care demo entries are stored only in the browser's local storage. The static frontend does not upload them to an IGERS server.

Browser location is used only to update the client-side view when the visitor explicitly grants permission.
