SECURITY / DEPLOYMENT REQUIREMENTS
- Keep authorized-feed-config.js blank on public GitHub Pages.
- Do not put secrets, tokens, private camera URLs or restricted counts in client code or a public repository.
- Deploy restricted-data views on an agency-approved private origin protected by SSO/VPN and required logging. Never expose the gateway directly to the internet.
- Configure upstream URL/host/token using a private environment or secret manager after the data owner provisions access.
- Validate the API schema, units, source timestamp/timezone, freshness, rate limits and privacy/retention rules with the owner.
- Test public map/weather/USGS/ADS-B feeds separately; these are different sources and cannot establish real ground-border traffic.
