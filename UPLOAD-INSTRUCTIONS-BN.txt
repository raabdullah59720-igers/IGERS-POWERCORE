IGERS POWERCORE — Satellite / Internet Link Speed Test add-on
Release: 2026-10-16-link-speed-v1

এই ZIP-টি পুরো ওয়েবসাইট নয়; বর্তমান GitHub Pages সাইটের নতুন Atmosphere/RF এবং Secure Connectivity অংশ অক্ষত রেখে শুধু Mbps speed-test panel যোগ করার add-on। পুরোনো IGERS-POWERCORE-main (20).zip দিয়ে সম্পূর্ণ index.html overwrite করবেন না।

১) ZIP extract করুন।
২) শুধু satellite-link-speed.js ফাইলটি আপনার GitHub repository-এর বর্তমান main branch-এর root-এ upload করুন—index.html-এর পাশে যেখানে অন্যান্য .js ফাইল আছে।
৩) GitHub-এ বর্তমান index.html খুলে Edit (✏️) চাপুন। শেষের দিকে </body> ট্যাগের ঠিক আগের লাইনে এই লাইনটি যোগ করুন:
   <script src="satellite-link-speed.js?v=20261016-mbps-v1" defer></script>
৪) Commit changes করুন। Actions → Pages-এ deployment Success না হওয়া পর্যন্ত অপেক্ষা করে সাইট Ctrl+Shift+R দিয়ে hard refresh করুন। Navigation-এর Infrastructure & Network group থেকে “Link Speed Test (Mbps)” খুলুন।

গুরুত্বপূর্ণ সীমা:
- Panelটি browser-এর বর্তমান network path দিয়ে public Cloudflare speed-test edge-এর download/upload Mbps ও latency মাপে। Test সফল হবে কি না তা browser, ISP, CORS/network policy এবং endpoint availability-এর ওপর নির্ভরশীল।
- এই test একাই satellite ISP/terminal সক্রিয় আছে প্রমাণ করে না; সে জন্য provider/modem telemetry দরকার।
- GitHub Pages-এর static page নিজে Windows/Android-এ system-level VPN tunnel তৈরি করতে পারে না। Tunnel-এর জন্য native VPN app এবং provider-এর বৈধ profile/config দরকার।
- এই add-on ফাইলে system file, credentials, VPN keys বা provider password নেই।
