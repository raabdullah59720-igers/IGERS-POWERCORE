## App shell behavior added

- Dashboard launcher is the default view.
- Workspace card opens a list of the original navigation targets.
- Selecting a feature focuses its existing top-level panel; the original panel DOM and module code are not deleted.
- Back-to-workspaces control returns to the launcher.
- Resize events are dispatched after panel navigation to help canvas-based panels recalculate dimensions.
- Existing system-control/admin shortcuts were wired through the app-shell router so they can open their target panel instead of trying to scroll to a hidden section.

## Runtime certification limits

- A headless Chromium render/click-through attempt timed out in this build environment; therefore a full browser E2E pass is **not certified**.
- External live providers were not independently certified. Actual feed health remains dependent on the user’s network, provider availability, API keys and browser CORS behavior.
- The uploaded source archive referenced a missing boundary fallback asset. A **generalized Natural Earth 1:110m public-domain outline** was supplied so the build and map fallback can load. It is for broad visual context only—not legal border demarcation, navigation or operational decisions.
- The shared password is checked in client-side code; it is a UI access gate, not server-side authentication.

## Release decision

Static source preservation, syntax, anchor, CSS, build and package checks passed. The compact ZIP is suitable for deployment testing, but the above runtime/provider limitations should not be interpreted as a guarantee that every external live feed will always be online.
